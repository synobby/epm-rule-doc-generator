# 2-minute demo script

Record with Loom, OBS, or Windows **Win + Alt + R** (Xbox Game Bar). Use the **live URL** in an incognito window. Upload the video to YouTube (Unlisted), Loom or Google Drive (anyone with the link) and test the link in incognito.

| Time | Show on screen | Say |
|---|---|---|
| 0:00–0:15 | App home page | "I'm an Oracle EPM consultant. When we inherit an application, business rules are usually undocumented, and reading them line by line takes hours. This app documents a rule in seconds." |
| 0:15–0:30 | Click **Load sample rule**; scroll the rule | "This is a calc script that allocates corporate OpEx by headcount, with nested FIX statements and run-time prompts. It's a sample rule, no client data." |
| 0:30–0:40 | Turn on **Mask member names**, click **Generate** | "For real projects I can mask member names before anything is sent to the AI." |
| 0:40–1:05 | **Documentation** tab | "The AI returns a fixed structure: purpose, FIX scope, dimensions, run-time prompts, step-by-step logic and risks. Same format every time, ready for a design document." |
| 1:05–1:20 | **Extracted facts** tab | "These facts are found by code, not AI: two FIX blocks with line numbers, members, functions. The app checks the AI against these and flags anything it can't verify." |
| 1:20–1:35 | **Teach me** tab | "For junior consultants, every line is explained in plain English with the concept it uses. This is how I'm learning Groovy myself." |
| 1:35–1:45 | Edit one cell, click **Download .docx**, open it | "I can edit before exporting to Word or Markdown." |
| 1:45–2:00 | GitHub repo: green Actions tick, then sidebar stats | "Every push runs secret scanning, linting and 48 tests in GitHub Actions, and the app logs basic usage without ever storing rule text. Thanks!" |
